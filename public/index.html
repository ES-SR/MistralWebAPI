API & Keys
Security & privacy. Your API key is entered by you and stored only in this browser (sessionStorage by default; optionally localStorage). It is used only by this page to call the configured API endpoint directly — the local server only serves this static interface and never receives or stores your key, and no key is shipped in the code. The key is visible in browser devtools / network traces by design (it is your own key). Browser extensions, local malware, or other local processes can still read browser storage or loopback traffic — that is outside this app's control. Use a least-privilege, revocable key (not your production key), and rotate it if you suspect exposure. This app is served on 127.0.0.1 only; if you ever expose it beyond localhost, put TLS in front of it.
Each provider has its own saved key, base URL, and defaults.
