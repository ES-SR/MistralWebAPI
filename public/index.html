API
Security & privacy. Your Mistral API key is entered by you and stored only in this browser (session storage by default; optionally localStorage). It is used only by this page to call api.mistral.ai directly — the local server only serves this interface and never receives or stores your key, and no key is shipped in the code. The key is visible in browser devtools / network traces by design (it is your own key). Browser extensions, local malware, or other local processes can still read browser storage or loopback traffic — that is outside this app's control. Use a least-privilege, revocable key (not your production key), and rotate it if you suspect exposure: a leaked key can incur billable usage and expose the prompts and documents you send. This app is served on 127.0.0.1 only; if you ever expose it beyond localhost, put TLS (e.g. a reverse proxy) in front of it.
